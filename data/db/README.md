# data/db — the trip database

Generated by `python3 data/scripts/build_db.py` from the untouched pulls in `data/raw`.
Re-run it after changing the route; everything here is derived.

| file | rows | what |
|---|---|---|
| `attractions.json` | 778 | sights within 10 km of the driven route |
| `food.json` | 993 | restaurants, cafés, bakeries, bars |
| `fuel.json` | 189 | petrol stations |
| `groceries.json` | 102 | supermarkets — `cat` splits full shops from village stores |
| `stays.json` | 678 | accommodation, reference only |
| `days.json` | 8 | derived per-day summary incl. longest fuel gap |

## Record shape

Every row in every category file is the same shape:

```json
{
  "id": "n122275354",
  "name": "N1",
  "lat": 64.54403, "lng": -21.91039,
  "kind": "fuel", "cat": "fuel",
  "days": [[0.0, 0]],
  "town": false,
  "phone": "+3544401333",
  "address": "Brúartorg 1, Borgarnes"
}
```

`days` is `[[km, dayIndex], ...]` — **one entry per day of the ring whose road passes
within 10 km**, nearest first. It is a list because 1,423 places sit on more than one
day's route; anything that picks a single day will put things on the wrong day.
`dayIndex` is 0-based (0 = Oct 3).

`town` marks the Reykjavík / Selfoss / Akureyri / Keflavík built-up areas. Filter it out
to see the roadside reality — it is roughly half the rows and almost all of days 1 and 8.

`planned` (attractions only) means it is already a stop in the itinerary.

## Caveats

- **Opening hours are OpenStreetMap volunteer data.** 57% of food rows have them and
  they are often stale. Treat as "this place exists", not "this place is open" — doubly
  so in October when a lot of rural Iceland closes for the season.
- Phone coverage is 35–41% for food and stays, 5% for fuel.
- `data/raw/rexby-things-to-do.json` is a Rexby export where 717 of 941 entries are
  paywalled and carry no name. Only the 224 named ones are usable.
